# ikamemo

Splatoon 3のバトルメモ生成ツールです。テンプレートから試合結果のメモファイルを生成します。

## 使い方

### バトルメモ生成

```bash
go run . -w "プラFR" -r エリア -s オヒョウ -o win
```

| フラグ | 省略形 | 説明 | 例 |
| -------- | -------- | ------ | ----- |
| `--weapon` | `-w` | 使用武器名 | `-w "プラFR"` |
| `--rule` | `-r` | ルール（部分一致対応） | `-r エリア` `-r ヤグ` |
| `--stage` | `-s` | ステージ名（部分一致対応） | `-s オヒョウ` `-s 空港` |
| `--outcome` | `-o` | 結果（win/lose） | `-o win` |

### 射程差アドバンテージ計算 (`range`)

射程差を基に、長射程側が何秒・何発分有利かを計算します。

#### ブキ名で計算

```bash
go run . range -a バレル -b スシ
```

ブキデータはコマンド実行時に [wikiwiki.jp/splatoon3mix](https://wikiwiki.jp/splatoon3mix) から自動取得します。
ネットワークが利用できない場合は `--offline` フラグでフォールバックデータを使用できます。

```
=== 射程差アドバンテージ計算 ===
長射程: バレルスピナー (射程 4.1, 重量 中)
短射程: スプラシューター (射程 2.9, 重量 軽)
---
射程差: 1.20 ライン
移動時間有利: 0.500 秒 （スプラシューター側の移動速度 2.4 ライン/秒）
発数有利: 7.5 発 （バレルスピナーの発射速度 15.0 発/秒）
```

#### 数値を直接指定して計算

```bash
go run . range --range1 4.1 --range2 2.9 -W 軽 -f 15
```

#### ブキ一覧と重量クラス別移動速度を表示

```bash
go run . range
```

#### `range` サブコマンドのオプション

| フラグ | 省略形 | 説明 | 例 |
| -------- | -------- | ------ | ----- |
| `--weapon1` | `-a` | 長射程ブキ名 | `-a バレル` |
| `--weapon2` | `-b` | 短射程ブキ名 | `-b スシ` |
| `--range1` | - | 長射程値（ライン） | `--range1 4.1` |
| `--range2` | - | 短射程値（ライン） | `--range2 2.9` |
| `--weight` | `-W` | 短射程側の重量クラス（軽/中/重） | `-W 軽` |
| `--fire-rate` | `-f` | 長射程ブキの発射速度（発/秒）。省略するとブキ名登録値を使用 | `-f 15` |
| `--offline` | - | スクレイピングをスキップしてフォールバックデータを使う | `--offline` |

#### 計算ロジック

- **射程差** = 長射程 − 短射程（ライン）
- **移動時間有利** = 射程差 ÷ 短射程側の移動速度（秒）
- **発数有利** = 移動時間有利 × 長射程側の発射速度（発）

重量クラス別移動速度:

| 重量 | 移動速度 |
| ---- | -------- |
| 軽   | 2.4 ライン/秒 |
| 中   | 2.0 ライン/秒 |
| 重   | 1.6 ライン/秒 |
