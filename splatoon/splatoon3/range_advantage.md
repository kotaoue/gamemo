# 射程差アドバンテージの計算

射程の長いブキが、短射程のブキに詰めてこられている間に「何秒・何発分」撃てるかを求める計算メモ。

## 前提

### 重量クラスと移動速度

| 重量クラス | 移動速度 |
| --------- | ------- |
| 軽 | 2.4 ライン/秒 |
| 中 | 2.0 ライン/秒 |
| 重 | 1.6 ライン/秒 |

## 計算式

```text
射程差（ライン） = 長射程 − 短射程
移動時間有利（秒） = 射程差 ÷ 短射程側の移動速度
発数有利（発）   = 移動時間有利 × 長射程ブキの発射速度
```

## 計算例：バレル vs スシ

| 項目 | バレルスピナー | スプラシューター |
| ---- | ----------- | ------------- |
| 射程 | 4.1 ライン | 2.9 ライン |
| 重量 | 中 | 軽 |
| 発射速度 | 15.0 発/秒 | 10.0 発/秒 |

```text
射程差         = 4.1 − 2.9          = 1.2 ライン
移動時間有利   = 1.2 ÷ 2.4（軽）   = 0.5 秒
発数有利       = 0.5 × 15.0         = 7.5 発
```

→ スシが射程差を詰めきるまでに、バレルは **7.5 発** 撃てる。

## 主なブキのデータ

| ブキ名 | 射程 | 重量 | 発射速度 |
| ------ | ---- | ---- | ------- |
| バレルスピナー | 4.1 | 中 | 15.0 発/秒（一周チャージ 48F = 0.8秒 で 12発） |
| スプラシューター | 2.9 | 軽 | 10.0 発/秒（6F 間隔） |
| .52ガロン | 3.2 | 中 | 5.7 発/秒（約 10–11F 間隔） |
| .96ガロン | 3.6 | 重 | 3.0 発/秒（約 20F 間隔） |
